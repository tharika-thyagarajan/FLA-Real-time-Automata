# Real-Time Applications Using Finite Automata

## FLA Assessment Task 2

**Institution:** SRM Institute of Science and Technology, Tiruchirappalli

**Department:** Artificial Intelligence and Machine Learning

**Course:** Formal Language and Automata

## Project Overview

This project demonstrates the practical applications of Deterministic Finite Automata (DFA) using Python.

### Applications

1. Password Verification System
2. Email Format Validator
3. ATM PIN Verification System

## Technologies Used

- Python 3
- PyCharm
- Finite Automata (DFA)

## DFA Concepts

Each application uses:
- Set of states (Q)
- Input alphabet (Σ)
- Transition function (δ)
- Initial state (q0)
- Final states (F)

## Project Structure

- main.py
- password_verification.py
- email_validator.py
- atm_pin_verification.py

## Features

- Interactive terminal-based application
- DFA-based input validation
- Accepted and rejected outputs
- Automated test cases
- Separate validation modules

## How to Run

1. Install Python 3.
2. Open the project in PyCharm.
3. Run main.py.
4. Select an application from the menu.
5. Enter the required input.

## Testing

Each application includes five accepted and five rejected test cases.

## Conclusion

This project demonstrates how Deterministic Finite Automata can be applied to real-world input validation problems using Python.
